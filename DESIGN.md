# Image Desk interface

A small production desk for images: charcoal tool header, off-white work surface, lime selection accents, square controls and monospaced filenames. The preview is the main object; settings form a separate inspector.

The file strip is for choosing and comparing files, not for nesting scrollable detail panels inside thumbnails. Keep filename, export dimensions, size and download state readable. The stage caption must describe the displayed image, including processed dimensions. Long filenames truncate visually but remain available in the title and accessible name.

All image work happens on this device. Keep the original, process sequentially, release object URLs, load ZIP support only when exporting an archive and preserve explicit errors for unsupported or oversized files. Changing export settings invalidates old results. Never imply files have been uploaded or saved remotely.

Desktop fits the preview, inspector and batch action into one viewport. Small screens switch between Preview and Export settings. Preserve native file selection, drag/drop, keyboard controls, before/after preview and individual downloads.
